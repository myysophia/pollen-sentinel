# 个人症状日记归档

本目录存放**本人自愿公开**的鼻炎症状日记 `diary.json`，随 Git 仓库一起版本化保存，便于：

- 跨设备查看（GitHub Pages 上的日报会自动叠加本归档，只读展示）；
- 长期回溯症状-花粉-用药关系，复诊时导出给医生；
- 未来积累足够样本后，训练个性化症状预测（L3）。

## 字段说明

每条记录按日期为键：

| 字段 | 含义 |
|---|---|
| `sym` | 5 项症状 0-3 分：sneeze 打喷嚏 / snivel 流清涕 / stuffy 鼻塞 / itch_nose 鼻痒 / itch_eye 眼痒流泪 |
| `total` | 症状总分（0-15） |
| `checks` | 夜间憋醒与用药：鼻喷激素 / 口服抗过敏 / 滴眼液 / 盐水洗鼻 |
| `out` | 户外时长：<1小时 / 1-3小时 / >3小时 |
| `mask` | 口罩：无 / 是 / N95/KN95 |
| `note` | 自由备注 |

## 更新流程

1. 在日报页面填写并「保存今日记录」（先存浏览器本地）；
2. 点击「导出备份(JSON)」得到导出文件；
3. 把其中的日期记录合并进 `diary.json` 的 `records`，提交到仓库；
4. 下次流水线运行后，Pages 日报即自动叠加。

> 隐私提示：本仓库为**公开仓库**，这里的内容任何人可见，请勿记录真实姓名、联系方式、就诊号等身份信息。`diary.example.json` 仅为格式样例。
